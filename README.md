# OpenClaw Integrated Healing Agent System

A multi-agent autonomous system powered by OpenClaw framework and MiMo-V2-Pro models, designed for automated integration testing, localized database healing, and multi-dimensional text chunk querying.

## 🚀 System Architecture
This project implements a long-chain reasoning architecture featuring four core autonomous agents:
- **Architect Agent**: Conducts topological dependency analysis on workspace source files.
- **Coder Agent**: Auto-generates robust integration test cases with end-to-end user session verification.
- **Tester Agent**: Executes scripts in sandboxed environments, capturing execution logs and stack traces.
- **Debugger Agent**: Conducts self-reflection loops to identify root causes and hot-fix legacy code flaws.
